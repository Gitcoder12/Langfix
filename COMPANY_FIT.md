# Langfix — Company and Team Fit

Potential skills/employer fit only, not customer or endorsement claims.

## Project thesis

A command-line code quality assistant that scans several programming languages, reports issues and can call formatters to fix files.

## GitHub

**Relevant areas:** Code scanning, developer productivity, CI and repository automation.

**Potential roles:** Developer Tools Engineer, Code Quality Engineer, Software Engineer or Security Engineer.

**Evidence to build:** Python tool using ThreadPoolExecutor, incremental file caching, formatters including Black/Prettier/gofmt, security-pattern checks and complexity analysis. The audit found that README promises a dashboard file not in the tree and formatter execution uses questionable shell/argument handling without reliably checking exit codes. Do not claim a file was fixed unless the formatter actually succeeded.
